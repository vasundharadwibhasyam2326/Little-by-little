LITTLE BY LITTLE — INSTALLABLE WELLNESS TRACKER

Files:
- index.html: the app
- manifest.json: home-screen install settings
- sw.js: offline cache
- icon.svg: app icon

To put it on your Android home screen:
1. Create a new GitHub repository (for example: little-by-little-tracker).
2. Upload ALL four app files (index.html, manifest.json, sw.js, icon.svg) to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Open the published HTTPS URL in Chrome on your Android phone.
6. Tap the Chrome ⋮ menu > Add to Home screen (or Install app) > Add.

Notes:
- The app stores check-ins and notes locally in that browser on that device.
- Data may not transfer to another phone/browser or survive clearing browser data.
- The app is a gentle habit tracker, not medical advice.
- Keep all four files together in the repository root.
